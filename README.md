# 📋 IT.TEAM — Академический Менеджер Задач

**IT.TEAM** — это адаптивное веб-приложение (PWA) для автоматического контроля дедлайнов и синхронизации учебного процесса академической группы. Проект разработан по методологии *Mobile-First*, имеет кастомный интерфейс в глубоких темных тонах и адаптивную систему индикации горящих сроков.

## 🔥 Ключевые возможности

*   **Автоматическая сортировка:** Все учебные задачи автоматически выстраиваются по степени срочности (самый близкий дедлайн всегда находится вверху списка). Выполненные задачи автоматически опускаются вниз.
*   **Умная цветовая индикация дедлайнов:**
    *   🟡 **Желтый цвет границ карточки** — до сдачи лабораторной/работы осталось менее 24 часов.
    *   🔴 **Красный цвет границ карточки** — время на сдачу истекло (задача просрочена).
*   **Постоянный фоновый мониторинг:** Приложение каждую минуту в реальном времени пересчитывает оставшийся срок задач без необходимости ручного обновления страницы.
*   **Мгновенная фильтрация:** Быстрое разделение задач на вкладки «Все», «Текущие» и «Выполненные».
*   **Локальная база данных:** Данные сохраняются на стороне сервера в формате `JSON`. Ваши задачи, приоритеты и отметки выполнения не пропадут после перезапуска ПК или закрытия вкладки.
*   **Бесшовная навигация:** Поддержка переходов по разделам «Задачи», «Календарь» и «Группа» с помощью нижнего таб-бара.

## 🛠 Архитектура и стек технологий

Проект разделен на независимый клиентский интерфейс и легковесный бэкенд-сервер:

*   **Backend:** Python 3.10+ (FastAPI, Uvicorn, Pydantic)
*   **Frontend:** Vanilla JS (ES6+), HTML5, CSS3 (Custom Properties / CSS-переменные)
*   **Database:** Локальное файловое хранилище (JSON)

## 🚀 Пошаговая инструкция по запуску (для Windows)

### Шаг 1. Открытие проекта в Visual Studio Code
1. Откройте VS Code.
2. Перейдите в меню `Файл` -> `Открыть папку...` и выберите директорию с проектом.
3. Откройте встроенный терминал, нажав комбинацию клавиш **`Ctrl + \``** (или `Терминал` -> `Создать терминал`).

### Шаг 2. Настройка виртуального окружения (venv)
В окне терминала поочередно выполните следующие команды:

1. Создайте изолированную среду:
   ```powershell
   python -m venv venv
   ```
2. Разрешите выполнение скриптов в PowerShell (требуется для обхода защиты Windows):
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
   ```
3. Активируйте виртуальное окружение:
   ```powershell
   .venv\Scripts\activate
   ```
   *В начале строки терминала должна появиться зеленая плашка `(.venv)`.*

### Шаг 3. Установка библиотек и запуск
1. Установите зависимости одной командой:
   ```powershell
   pip install -r requirements.txt
   ```
2. Запустите веб-сервер:
   ```powershell
   python main.py
   ```

После того как в консоли появится строчка `INFO: Uvicorn running on http://127.0.0.1:8000`, зажмите клавишу **`Ctrl`** и кликните по ссылке мышкой. Приложение откроется в браузере.

## 🔒 Безопасность и отказоустойчивость
*   **Защита от XSS:** Все текстовые поля (название лабораторных и предметов) проходят очистку через функцию `escapeHTML` перед выводом на экран, блокируя инъекции вредоносных скриптов.
*   **Автономность базы данных:** Бэкенд-сервер при первом старте самостоятельно проверяет наличие папки `static` и файла `tasks.json`. Если они отсутствуют, он создаст их автоматически без аварийного завершения программы.
